### Title: Release job fails due to unsupported Yarn version flag\n\nThe 🏷️ Create Tag and Release workflow fails during the version bump step because the command:\n`yarn version --new-version "$NEW_VERSION" --no-git-tag-version`\nis not supported in Yarn v2+ (Berry). The logs show:\n`Unknown Syntax Error: Unsupported option name ("--new-version").`\n\n### How to fix:\nReplace the step in `.github/workflows/release.yml` to:\n`yarn version "$NEW_VERSION" --no-git-tag-version`\nThis will resolve the syntax error and properly bump the version.\n\n### Reference: https://github.com/m-idriss/photocalia/issues
