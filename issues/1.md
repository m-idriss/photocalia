### Issue: Release job fails due to unsupported Yarn version flag

**Body:**
The 🏷️ Create Tag and Release workflow fails during the version bump step because the command:

yarn version --new-version "$NEW_VERSION" --no-git-tag-version

is not supported in Yarn v2+ (Berry). The logs show:

Unknown Syntax Error: Unsupported option name ("--new-version").

**How to fix:**
Replace the step in .github/workflows/release.yml to:

yarn version "$NEW_VERSION" --no-git-tag-version

This will resolve the syntax error and properly bump the version.
