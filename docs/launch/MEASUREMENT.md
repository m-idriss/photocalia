# Launch measurement

## UTM convention

Use lowercase values and one canonical campaign name.

`utm_source`: `producthunt`, `linkedin`, `x`, `youtube`, `alternativeto`, `reddit`, directory hostname

`utm_medium`: `launch`, `company_page`, `organic_post`, `demo_video`, `directory`, `community_post`

`utm_campaign`: `brand_launch_2026`

Optional `utm_content`: asset or post variant such as `maker_comment`, `demo_en`, `post_fr`

## Funnel

Track aggregate counts only where consent and configuration permit:

1. verified listing/profile became live;
2. qualified visit to PhotoCalia;
3. converter/sign-in interaction;
4. conversion request started;
5. review shown;
6. ICS export completed;
7. return visit or plan-page visit.

Do not equate page views with product success. The primary launch indicators are completed reviewed exports, useful feedback themes, support load and repeat usage.

## Review cadence

At day 2, verify links, indexing, replies and error/support signals. At day 7, compare sources by reviewed exports and summarize objections/questions. At day 30, keep channels that produced qualified use or durable citations; update or retire inaccurate listings.

Never use hidden tracking in uploaded documents or expose user-level conversion content in a campaign report.
