# PhotoCalia acquisition readiness

Prepared: 7 August 2026. This document is an operational index, not a valuation or a warranty.

## Buyer-facing strengths verified in the frontend

- Working bilingual product and marketing experience with English and French canonical routes.
- Installable Angular 22 PWA shell with responsive desktop and mobile layouts.
- Live Google authentication, quota-aware conversion flow and paid subscription checkout integration.
- Public usage evidence sourced from the production API rather than hard-coded counters.
- Three plans, monthly/yearly billing presentation and Stripe-hosted payment handling.
- Forty-four sitemap URLs, prerendered pages, structured data and targeted SEO landing pages.
- Editable AI output before ICS export, reducing the operational risk of extraction mistakes.
- MIT-licensed frontend, automated tests, linting, production build checks and dependency scanning.
- Security headers, consent controls, privacy policy, terms and legal notices.

## Improvements completed by the readiness audit

- Pricing quotas now use the production plans API, with accurate prerender fallbacks.
- Subscription FAQs no longer promise a self-service account feature that is absent.
- Stable translation URLs no longer receive a one-year immutable browser cache.
- Browser logging no longer sends a request for every successful API call.
- Logged request URLs exclude query strings and possible user identifiers.
- The public logging endpoint now enforces production origins and payload size limits.
- The PWA manifest no longer advertises an unsupported POST share target.
- Public version, runtime and deployment documentation is aligned with production.

## Items the owner must evidence before a transaction

These cannot be proven from the frontend repository and should not be guessed or embellished:

- Monthly recurring revenue, refunds, churn, conversion rate and payment processor statements.
- AI/API cost per conversion, gross margin and cloud invoices.
- Active-user definitions, retention cohorts and traffic-source quality.
- Backend source ownership, deployment reproducibility, backups and recovery tests.
- Stripe webhook idempotency, entitlement enforcement and cancellation operations.
- File retention/deletion behavior and data-processing agreements with every processor.
- Trademark/domain ownership and contributor intellectual-property assignments.
- Support workload, unresolved incidents, chargebacks and contractual commitments.

## Recommended data-room structure

1. Corporate and intellectual property.
2. Product architecture and source inventory.
3. Infrastructure and security controls.
4. Financial exports and unit economics.
5. Analytics and customer metrics with definitions.
6. Legal, privacy and processor agreements.
7. Operations, incidents, support and roadmap.

Provide exports or screenshots with their date, source and metric definition. Redact customer personal data and never place reusable credentials in the data room.

## Honest sale narrative

PhotoCalia is a deployed, bilingual micro-SaaS that solves a concrete manual-entry problem with an established conversion workflow, public usage, paid-plan infrastructure and an expanding organic-search footprint. The defensible value is the complete operating system around the converter—product experience, content, distribution, billing integration and deployment—not an unverifiable promise about future rankings or revenue.
