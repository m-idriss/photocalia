📅 About Photocalia

AI-powered photo to calendar conversion, built by Idriss

Our Mission

Photocalia was born from a simple frustration: you receive a flyer, a screenshot of a meeting invite, or a photo of a school schedule — and then you have to manually type every date, time, and location into your calendar. It's tedious, error-prone, and time-consuming.

We built Photocalia to eliminate that friction. Using advanced AI (GPT-4 Vision), our tool reads your images and PDFs, extracts all event details automatically, and generates a standard ICS calendar file you can import into Google Calendar, Outlook, or Apple Calendar in seconds.

Technology Stack

Photocalia is built with modern, production-grade technologies chosen for performance, security, and reliability:

Angular TypeScript Firebase GPT-4 Vision Cloud Functions PWA
  • Frontend: Angular Progressive Web App with responsive design
  • AI Engine: GPT-4 Vision for OCR and event extraction
  • Hosting: Firebase Hosting with global CDN
  • Backend: Firebase Cloud Functions on Google Cloud
  • Authentication: Google Sign-In via Firebase Auth
  • Output: Standard ICS (iCalendar) format
